# Adventure & Survival Expansion Mod

A comprehensive Minecraft Fabric mod for 1.21.1 that overhauls survival gameplay with:

- **Movement**: Double jump, wall jump, dodge dash
- **Combat**: Fist combos, parry shielding
- **Animals**: Wild boar, deer (with behaviors)
- **Villagers**: Guard villagers (hireable), Hunter profession (4 trade levels)
- **Equipment**: Boar tusk dagger, antler greatsword, hunter bow, hide armor sets
- **World Gen**: Hunter outpost structures, custom biome
- **Farming, Ranching, Hunting & Butchering**
- **Skills, RPG classes & Survival thirst**
- **Pets, Mythics & Bosses**

## Build

```bash
./gradlew build
```

JAR output: `build/libs/adventuremod-1.0.0.jar`
